Architecture, Data Flow, Components, and Fallback Strategy

🏗️ System Architecture & Data Flow

Client Layer (Next.js 15 App Router)
SidebarNav · CodePlayground · PredictionQuizCard · DiagnosticBanner · AdaptiveFollowUpCard · SocraticCoachPanel
API Routing Layer (Edge / Node API Routes)
/api/diagnose: Synthesizes prediction options & misconception maps.
/api/followup: Creates targeted remedial challenge for diagnosed flaw.
/api/chat: Socratic AI mentor for follow-up questions.
Intelligence & Diagnostics Engine
Primary: Gemini / OpenAI LLM Provider (when configured in .env.local)
Resilient Fallback: Built-in Diagnostic Knowledge Base for guaranteed instant operation.
Persistence
Browser localStorage (zero-friction, no mandatory signup barrier for hackathon reviewers).

🚀 Execution & Setup

Start local server:

npm run dev

Runs on http://localhost:3000. Verified zero-config fallback active.

🛡️ Failure Mode Protection

  • Missing LLM Key → Automatic seamless fallback to built-in curriculum
  • Invalid Code Input → Inline error guidance
  • Offline Browser → In-memory session continuation
