SkillMirror : Product Blueprint

Detailed Journey, Surface Layout, and Feature Specification

🗺️ The Core Journey Steps

Step 1
Select or Paste
Pick from curated mental model traps (closures, mutability) or paste custom code.
Step 2
Predict Output
Select expected console logs or return values before answers are revealed.
Step 3
Diagnose Trap
SkillMirror highlights the exact misconception in the learner's mental model.
Step 4
Targeted Challenge
Adaptive follow-up question directly addresses and cures the blind spot.

⚡ Key Product Behaviors

1. Code Preview & Challenge Stage

A sleek dark-mode syntax editor with line numbers and difficulty tags, showing the exact snippet under investigation.

2. Misconception Diagnostics

Explains why intuitive choices fail: "You assumed `var` had block scope; in JavaScript `var` is function-scoped."

3. Adaptive Follow-Up Generator

Synthesizes a tailored follow-up question that isolates the diagnosed misconception for immediate verification.

4. Socratic AI Coach & Metrics

Split-view conversational coach for progressive hints, accompanied by Strengths vs. Skill Gaps analytics.
